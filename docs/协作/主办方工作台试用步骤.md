# 主办方工作台试用步骤

更新日期：2026-10-11。建议用一场明确标注“测试”的比赛和两个自己的账号演练，避免通知真实选手。当前正常公网解析与实体手机访问未通过，可先用本机 `http://localhost:3000`。

## 先准备身份

主办方申请人、平台审批人应为不同账号；系统不允许本人审核自己的机构入驻申请。主办方账号与选手账号也分开测试，便于检查不同身份所看到的信息。主办方不因入驻就获得其他机构、赛事或私人团队空间的权限。

## 一次完整测试

1. 从网站顶部“主办方入驻”进入，填写机构与联系人资料、真实机构证明，提交入驻申请。
2. 由已有平台管理员进入 `/admin/organizers`，选择“通过入驻”，填写审核说明并确认。申请人不能自行通过审核。
3. 申请人进入 `/organizers/workspace`，创建明确标为测试的比赛，保存草稿。时间建议：报名现在开放、明天截止，后天开赛，第三天作品截止，第四天结束；逐个核对北京时间。
4. 在报名管理中展开“设置报名表”，填写标题和测试所需字段，开启“报名需要人工审核”，发布本场报名表。先发布表单，再核对公开范围并发布比赛。
5. 复制本场本站报名链接，自己在无痕窗口或另一台设备使用。链接可自行发布到社交平台，审核权限不会跟着链接公开。
6. 用选手账号注册或登录，确认仍回到这场比赛的报名页，填写并提交。查看本人待审核状态；创建团队空间或保存赛事卡片都不算报名成功。
7. 回主办方账号，通过本场报名管理查看资料并“通过报名”。切到另一场测试比赛时，确认没有混入上一场名单或草稿。
8. 编辑并保存本场入选通知模板，选“已通过”的对应选手，预览专属内容，再确认发布。选手刷新自己的通知，核对赛事、正文、时间和入场方式。
9. 测试组队、赛程、答疑和提交作品入口。正式队伍是比赛名单，私人团队空间用于协作；建立关联不授权主办方读取私人AI或准备草稿。

## 邮件和回执怎么看

先测试站内通知闭环。需要外部邮件时，主办方可在本机构发信设置中验证自己的QQ/163/126/Gmail账号；授权码只填设置界面，不放聊天或测试文档。登录验证码仍由平台身份系统发送。

“站内已发布”“邮件排队”“邮件服务已接受”“实际收到”“选手已读”分别检查，不能把其中一个当成全部成功。真实邮箱投递与手机Cookie仍需实体设备验收；浏览器隔离夹具通过不代表已经给真实用户发过邮件。
