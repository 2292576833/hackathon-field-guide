## 已完成

- 默认自由画布；新用户使用公共 `initialCollaborationCanvas()` 预置待办、团队进度、队友、流程和文档。初次读取不自动 PUT；已有保存布局沿用其坐标、尺寸和缩放。视图偏好改用 v3 键，旧版默认协作视图不再决定本轮初始视图；用户本轮主动选择的阅读模式仍可保存。
- 去外层视觉卡框、重复组件标题、常驻保存成功说明及全局尺寸调整教学。空间名、邀请与空间 AI 留在粘性顶部；阅读模式、刷新与整理归顶部小菜单，组件操作归组件箱或各组件小菜单。
- 桌面以 ResizeObserver 读取组件实际宽高。流程按内容实际宽度展开，未套380px窄框；只有未保存的新默认布局会按真实高度安排流程及文档。旧私人布局不自动重排，可主动通过“整理成单列”调整。
- 画布边界同时包含实际内容及拖动预览，最小2400×1600，并在最右与最下内容外至少留400px。水平滚动在画布内，顶部“回到内容”和菜单“查看组件”可定位已有内容。流程移除/折叠后保留不可见的真实表单入口，不额外铺出第二份流程或撑宽页面。
- 长按450ms激活移动，无抓手。激活前位移超过8px即取消；支持指针离开、取消、丢失捕获、Escape、窗口失焦及屏幕断点切换时取消。移动坐标包含水平画布滚动和窗口垂直滚动差值。
- button/input/select/textarea/a/summary/dialog、可编辑区与图节点优先本身交互。文档 `data-space-document-text` 与 textarea 保留选字/编辑；`data-space-document-body` 框沿约6px可长按。已有文字选区阻止长按激活。
- 普通 wheel 在桌面组件上缩放，范围沿用公共0.5–2倍限制；空白画布保留原生滚动。输入目标或同组件正在聚焦编辑的输入区保留原生滚轮；ctrl/meta保留浏览器行为。已消费事件、`data-graph-node`及旧节点标记均不触发父组件缩放。
- 手机整页单列，忽略桌面坐标与缩放的显示效果；长按预览使用 CSS order，不在捕获期间搬移DOM，避免重排丢失指针捕获。松手仅更新items顺序，合并当前条目的桌面x/y/width/height/scale，不覆盖桌面字段。菜单提供往前/往后及键盘可操作的等价入口。
- 不对整个组件设置 `touch-action:none`。非passive touchmove只在active drag时preventDefault，未激活时保持原生阅读滑动。
- 快速布局变化180ms合并并串行PUT；慢请求返回时保留更晚的屏幕预览，后续请求使用更新后的revision。409及未知保存结果保留画面、未确认保存与错误，提供核对重试/读取保存版本入口；恢复GET期间暂时禁用布局修改，避免丢掉中途手势。没有自动覆盖另一窗口的新版本。
- 小菜单保留折叠、移除、左右上下/手机排序、宽度、缩放与恢复100%；文档不增加外层菜单框，使用组件箱管理摆放，显式折叠后有可键盘操作的展开入口。
- 空间AI按需挂载，继续复用现有本人/空间权限、历史与共享逻辑。弹窗使用唯一标题ID、独立滚动和关闭后焦点返回，并处理快速关闭/重开的旧close事件及账号/空间切换。
