## 完整分析与折叠交互复测

四组合中两次赛事页检查均验证了全部 8 张卡：默认“查看完整分析”未展开；展开后包含“适合谁”“需谨慎的情况”“准备下一步”“待确认”四组，每一条保存的 `fit`、`risks`、`preparation`、`unknowns` 文本均能在完整分析中匹配。原文摘要精简没有丢弃这些 DSH 建议。展开来源后，每条已保存来源摘录和 URL 也仍在；每张展开期间无横向溢出，随后关闭恢复默认状态。

页级“查看更新详情”默认关闭，键盘聚焦后按 Enter 可展开读取最近完成时间及配额说明，再按 Enter 可收起。手机“更多待更新位置（16 个）”默认关闭，展开后等待位置数量仍正确。默认首屏单独 reload 捕获时，8 张卡的展开详情数量为 0，页级更新与等待位置详情也均为关闭。

最终按钮上移版本另外展开了 AMD 旧卡：展开内容的提示为“参赛判断信息不完整，以下保留已有 DSH 分析供核对。”，没有再要求“展开完整分析”。四组标签均在，每条已保存 AMD 分析文本都匹配；展开后仍无横向溢出。最新一次 GET reload 与数据 GET 均为 200，页面错误、失败 GET、非 GET 均为 0；默认 8 张卡均无展开详情。
