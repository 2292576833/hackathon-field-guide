## 场景

- 真实公开快照命中传给模型，真实摘录、类型、更新时间、站内入口与结果体积限制保留；模型结果仍固定标明 DSH。
- 无命中保留空结果和说明，模型虚构链接 ID 被拒绝。
- 外站、跳转参数、编码穿越及伪装为公开的空间链接不会进入公开检索。
- 会话和项目权限先于来源读取与模型请求校验。
- 模型调用期间公开资料撤下、修改或无法复核均以 409 阻止旧答案返回；已完成请求仍记账。
- 当前空间作品目标经 M02 真实修改后阻止旧摘要返回；其他实际私人空间的资料不被检索。即便用户问 PPT 模板、检索未命中空间摘要，只要模型输入另行带入旧空间摘要，也需同样拒绝旧回答。
- 初次读取公开资料失败时保留本站原创说明，并明确目录覆盖限制；回复仍需模型处理。
- DSH 未配置不使用检索静态回答；未知模型请求记账并禁止自动重发。

## 隔离边界

使用 `createDatabase({})` 创建隔离 PGlite 并执行既有迁移，账号、M02 项目、权限、AI 任务和费用账本均走实际服务。公开来源 Port 读取测试库专用 `navigator_search_fixture` JSONB 快照表，明确是验收夹具，不等同于资源运营发布链路验收。模型为显式测试 Port，不发送任何外部请求、不使用真实 DSH、不产生费用，不读取本机 `.env.local`。

来源读取器的真实模块映射与检索纯函数，由相应负责人另行测试；本文件验证导航员组合、权限与回答时来源一致性。
