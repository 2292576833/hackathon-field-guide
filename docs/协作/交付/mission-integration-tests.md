# 任务式参赛根应用集成验收

日期：2026-10-09。负责人：主会话内部代理 `mission_task_claims`。本轮临时文件授权仅为 `src/server/team-mission-integration.test.ts` 与本交付文档；交付后停止编辑并交还主会话。

## 已完成

新增 10 项 Node 内置测试，通过实际 `createApplication`、根路由 `dispatch`、根认证会话、根模块组合与独立 PGlite SQL 数据库，覆盖：

1. 根迁移 028–031 在隔离数据库实际应用；未登录、其他空间账号、已撤销会话无法读取新增私有接口。
2. 团队 AI 对话按账号、空间隔离。客户端传入其他账号不能切换身份；清除一个空间对话不清除其他空间或导航员历史，不抹掉请求账本。
3. 未配置 DSH 时，团队聊天、项目可行性和参赛名片生成诚实返回错误，不生成假成果、不创建模型执行记录。
4. 导航员回复持久化 `sourceId`。只有本人成功的助手消息可主动分享；其他账号来源、用户消息、执行请求 ID 均不能冒充有效来源。不自动公开原对话全文，重复提交不会多写共享卡片。
5. 导航来源被清除、共享建议被撤回后，后续团队 AI 上下文不再读取其内容；动态列表只保留不泄露正文的状态提示，上下文指纹变化。
6. 私有简历、年龄及 MBTI 在主动发布前不进入公开名片；按本人确认的字段发布，撤回后公开列表移除、个人资料保留。
7. 招募批准不等于入队。本人明确确认后，经实际 M02 邀请与接受流程成为成员；未确认、其他申请人不能加入，重复确认不额外生成邀请或成员。
8. 在 M02 已执行接受后模拟同一事务内失败，实际 SQL 回滚成员、邀请、项目版本及申请变化；恢复后可由本人安全重试。
9. 原批准人已不再是当前空间管理员时，旧批准不能继续授权入队。
10. 外站 Origin 与已撤销会话在修改资料或共享建议前被拒绝，无持久化副作用。

## 隔离与模拟边界

每个测试使用 `createDatabase({})` 创建独立、内存模式的真实 PGlite PostgreSQL 引擎，不读取 `.env.local`、生产嵌入式目录或远程数据库，不启动后台 worker。只在该隔离数据库运行根迁移，不修改已应用迁移文件。

导航员来源分享的两项测试通过显式注入的测试模型端口产生成功回复；认证、会话、预算账本、执行记录、消息持久化、分享来源校验、路由与模块服务均使用根实现。模型输出不代表真实 DSH 生成质量或外部连接成功。对话清除隔离用失败请求关联的测试用户消息建立历史，不伪造成功助手来源。

本轮未运行生产构建、网站启动、实际生产迁移、付费模型或网络请求。浏览器完整操作体验、公网访问、真实 DSH 回答质量，以及多连接 PostgreSQL 并发验收仍由主会话按最终环境执行。
