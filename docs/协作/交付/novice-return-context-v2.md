# 萌新全流程：个人资料与登录回跳浏览器验收

日期：2026-10-09。仅新增授权文件 `tests/e2e/novice-return-context-v2.spec.ts` 与本交付文档；未修改产品实现。交付后停止编辑，文件交还主会话。

## 已完成与已验证

采用已有 `isolatedWorkspace`：浏览器展示本机已经构建的真实页面，所有 API 请求交给独立内存 PGlite 中的真实应用、迁移和 `dispatch`。外站请求阻止，验证码只从该隔离开发邮箱读取。两个用例都使用 375px 手机视口。

### 用例一：缺少个人资料时保留所选比赛

- 人工准备一条名称、摘要、依据均明确写明“隔离练习”的 Discovery 卡；不代表真实比赛或模型分析，没有模型调用。
- 打开该赛事参与计划，确认资料不齐时生成按钮禁用。
- 点击“去补全个人画像”，URL 保留赛事 ID 并定位到画像区域。
- 在真实表单填写首次参赛、无开发经验、城市和每日时间，点击保存；使用真实接口读取持久结果确认字段。
- 点击“返回所选比赛，继续制定计划”，仍是原赛事，重新读取已保存画像后生成按钮可用。
- 检查该流程没有 `POST me/participation/plans`、模型用量或外站访问；手机无横向溢出、无页面脚本错误。

### 用例二：访客注册/登录保留资源与 GitHub 上下文

- 从带中文搜索、全部合法筛选和分页位置的资源目录点击顶部登录，再切换注册。
- 通过真实注册表单及隔离开发邮箱验证码完成验证，URL、搜索输入、React 技术栈、排序与分页 query 保留。
- 以该账号通过真实接口创建练习团队空间。
- 新访客浏览器从带该空间 ID 的 GitHub 教程入口登录，同邮箱恢复原账号；返回原教程 URL，显示有权限的当前空间，并提供该空间的代码与提交入口。
- 为避免等待验证码重发冷却，仅将隔离应用的测试时钟推进 90 秒；不改生产时间或认证策略。
- 没有 GitHub 写操作、模型用量或外站访问；手机无横向溢出。
