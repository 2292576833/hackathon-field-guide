## 验收场景

1. 375px 新空间：实际缺少目标时先补目标，单人可继续、邀请按需；首页六段指引依次介绍目标、报名/官方要求、分工/时间/计划、执行/交接、演示/正式提交、复盘/归档。使用原生 `summary` 的 Enter/Space 键逐段展开；每段有何时做、具体动作、核对条件与下一步。实际点击邀请链接打开弹窗但不生成邀请；`#space-settings` 和已收起的 `#project-goal` 链接均需展开目标详情并露出内容。核对五项空间导航保留、工具位置合理，只有实际支持空间上下文的路演/PPT/GitHub 链接带 `projectId`。
2. 当前计划读取失败：单独注入 503 读取故障，树显示未知并引导重读，不靠浏览初始化计划、打勾或完成状态。
3. 真实 M05 人工计划：Demo 的真实前置任务未验收时，录制任务不能开始，但脚本可并行。提交成果为待检查仍不解锁；只经有权限的真实进度/验收接口记录检查通过后才解锁。浏览指引树不改变这一事实，不把阶段或阅读当作任务完成。

## 隔离边界

- 使用已有 `isolatedWorkspace`，页面来自本机已构建应用，所有 API 经独立内存 PGlite、实际迁移和真实 handler。
- 账号、团队、邀请、计划和人工检查均为本用例自己的隔离夹具；不加载环境凭据或生产目录。
- 展开指引前后核对项目、M05 状态、账号导览记录和模型账本快照；浏览过程要求零 POST，树没有复选框。
- 验证页面不读取个人画像/出行/路演私有材料、不产生外部请求；不发送真实邮件，不调用模型，不操作 GitHub 或官方平台。
- 当前计划 503 仅模拟失败；其余读写使用真实 handler，不伪造模型成功结果。
- 不启动、构建、重启或发布网站，等待主会话声明新构建可用。
