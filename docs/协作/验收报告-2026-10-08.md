## 本机 DSH 接入

用户所指安装实际位于 `D:\dddsss`，执行文件为 `DeepSeek Harness.exe`，其内置 DSH/desktop-host 版本为 `0.2.0-rc.2`。网站服务端通过实际 Electron/SDK 子进程运行它。项目已安装的 npm `@deepseek-ai/dsh@0.2.1-alpha.1` 仍作为 API key/容器部署的另一种运行方式，本机当前使用 Desktop。

`.env.local` 中选择 `AI_PROVIDER=dsh` 和 `DSH_DESKTOP_DIRECTORY`，没有将账号 token 写入环境文件。规则分析、评分、分工、计划和复盘共用 DSH 模型适配器，导航员与来源分析也使用同一实际运行入口。

每次运行建立独立 home、profile 与工作目录；只复制官方 DeepSeek grant，不继承个人技能、插件、工具、浏览器账号、会话或其它服务密钥。Windows 在写入授权前设置并验证 owner-only NTFS ACL，Unix 设为 0700；不能建立私有目录时不启动模型，并按未发送处理。子进程退出后清理自己创建的临时目录；供应商拒绝授权时只影响临时副本，不修改原始个人登录信息。

外围和供应商自动重试均关闭。请求结果未知、未测量用量或返回不合法时，不伪装成功、不自动重发、不把未知费用写成零。实际 token 记录与按费率计算的预算金额分别保留，估算金额不是账号最终账单。

真实验证包括：实际 SDK 返回有效 JSON（118 输入 / 5 输出 token）；权限修复后的真实网站导航请求返回 HTTP 200、有效回复、两条站内链接，账本 settled（1682 输入 / 89 输出 token）。后者使用隔离 SQL 数据库与真实登录/接口，不读取真实参赛队伍数据。安全结果日志见 `.runtime/dsh-real-site-check.log`。

Windows 常驻服务须能访问这份安装和授权，并维持 DSH 登录。Linux/容器使用官方 API key 运行时，不能直接引用 Windows 安装目录。

## 发现与资源边界

当前原生发现由可信父进程控制隔离 DSH 账号的官方原生搜索，再安全读取公开来源并调用无工具 JSON 分析。此前官方来源 ETHGlobal/lablab 已验证，仍可切换单独使用。公开页面获取通过显式可信本机 CONNECT 代理，保留公开 DNS、固定 IP、TLS 和 robots；原生搜索子进程不继承代理或其他应用凭据。

本机每小时检查，每轮最多分析三场；日搜索上限 48、搜索与分析合计模型上限 120、日费用上限 1 USD。原生搜索属于付费模型调用，按保守完整窗口预留，真实用量返回后估算结算。结果已知但 usage 缺失按完整预留记账；请求结果未知则持久阻断。跨组交错选择，同一 URL 至少一天重抓，自动卡片始终未核验，项目正式规则沿用人工确认。

发送模型前持久化内容 hash 与未完成标记。有未确认模型结果时阻断整个 URL，正文变化、冷却、抓取失败、重启或另一地址成功均不授权自动重发；原 hash 与标记保留。未知 A → 正文 B → 回退 A 的 SQL 回归始终只调用一次模型。人工明确建立新的来源 run 是独立恢复路径。详见 `docs/协作/交付/operations.md`。

公开 `/events` 已去掉与分析卡片无关的人工库存筛选、空库存任务引导和采集配置。卡片先展示简短重点与官网按钮，完整分析和原文依据可以展开；采用二十四张游标分页，更多结果可继续查看。采集配置、费用与暂停留管理员后台；首次抓取失败和成功后重抓失败也会正确显示失败，而不会被未完成时间误判为“待处理”。官方提取规则变化有明确安全错误与中文说明。

`/library` 展示原创 GitHub、黑客松、网站、协作、交付与技能指南；`/resources` 展示审核后的策展资料，`/skills` 展示版本化技能与套餐。导航首次介绍可跳过、记忆与重放，介绍本身不依赖模型。
