## 1. 使用流程

主办方：用已验证账号申请机构，平台管理员人工核查 → 在正确机构使用模板建赛 → 发布本场报名表 → 预览发布赛事 → 复制完整报名链接发到自己的社交平台 → 在本场待审核列表处理报名 → 编辑标题、正文与样式，预览并明确发布给已通过选手 → 管理队伍、官方问答、行程后勤 → 正式收件与人工评审。

选手：打开对应比赛链接 → 注册/登录后返回原比赛 → 提交报名并查看审核结果 → 按实际比赛配置进入组队或官方安排 → 查本人入选通知、赛程和服务 → 确认正式名单与作品材料 → 查看正式收件回执与允许公开的结果。浏览、保存、通过审核、邮件接受、代码运行与正式收件分别记录。

评委只看到本人本场实际指派，先申报关系与回避，再人工评分。主办方不会因正式队伍关联私人团队空间而获得备赛权限，AI不录取或判分。

正式比赛在 /competitions，DSH未核验线索在 /events，私人备赛空间继续在 /app。抓取结果不冒充已认证主办方发布；生产正式比赛目前尚无真实主办方发布，不用测试赛事填充。
