# 体验与团队空间验收

日期：2026-10-09。依据：宪法 v1.5.0、体验整合规划、团队空间与多人邀请规划。三个实施会话及根接入代理均已交付并停止编辑。

## 当前结论

本轮功能已接入实际应用、数据库和新版网站，并完成浏览器贯通及手机尺寸布局验收。新版生产服务已重建并启动，本机和公网赛事接口均确认返回 8 条已保存分析。正式公网验收尚有一项未通过：现有 HTTPS 证书链报 `UntrustedRoot`，正常证书校验无法建立连接；跳过证书检查得到的 HTTP 200 不能记作可信 HTTPS 通过。需要为现有公网入口配置受信任证书，再验证手机访问。

## 验收中补齐和调整的内容

- 将官方赛道、个人职责意愿和共享摘要接入根服务与 API。赛道来自已确认主办方规则；任务套餐分类不替代官方赛道。共享仅投影本人明确选择的字段，成员身份和资料版本改变会使旧分工、计划输入需要复核。
- 将私人职责帮助接入通用 AI 队列、租约及预算。未知模型请求持久保留，同一内容换幂等键、跨日或并发调用不能绕过禁止重发。
- 实际应用多人邀请迁移。默认 1 人，可设置 1–50 人；消费记录唯一且不可改，重复活跃成员不占名额、不提权，已消费名额不返还。公开预览只显示必要空间、比赛、昵称、角色和额度信息。注册/登录保留邀请位置，加入需要本人明确确认。
- 保留一套团队空间实体与任务进度事实。成员报告完成后进入待检查，明确验收后释放依赖；更正请求与正式更正走独立根接口，原记录保留。
- 将路演与 PPT 的空间资料选择接入真实公共模块服务。资料先预览再确认，复合版本覆盖任务、进度与交付；生成前后复核当前权限和版本。计划、自检、团队检查、运行自报、平台提交分别说明，私人材料保存在本人账号。
- 统一“找比赛 / 我的参赛 / 工具与资料”导航、空间资料称呼和中文计划状态。补充 GitHub 教程链接及 AI 任务套餐说明；账号菜单支持点击外部和 Escape 收起。
- 修复登录返回位置丢失：技能固定版本、选中的团队空间及路演/PPT材料参数现在能在注册/登录后保留；外部跳转、重复参数和异常路径仍会拒绝。
- 任务页面将当前计划和任务进度放在编辑表单前；已有计划的调整工具、长说明默认折叠。手机标题和三步入口压缩后，“当前任务计划”可在 375 × 900 首屏看到，任务板向下少量滚动可见，没有横向溢出。
- 管理员后台加入“职责选择建议”任务的排队/运行计数及名称，保持只展示安全元数据。
- 邀请二维码在本地生成，与链接使用同一名额。邀请页面配置 `no-referrer`、`private, no-store`。

## 尚需目标环境验证

1. 公网受信任 HTTPS、真实手机打开、扫码和登录。当前证书链未通过，不能认定手机交付完成。
2. 两个真实用户账号及远程 PostgreSQL 的独立连接并发。隔离浏览器和 PGlite 事务队列不替代该项。
3. 本轮没有发送真实验证码、发起付费 DSH 或修改真实 GitHub 仓库。此前 SMTP 接受发送不等于本轮已确认实际收件；真实生成与仓库写入需按真实账号流程验收。
4. 展示上下文目前为 M06 事实读取使用短事务表 SHARE 锁，暂时串行化交付写入；锁不跨模型调用。扩大试用前可以改为所有 M06 写方统一采用项目锁。
5. 公网隧道接口曾出现短时超时，重试成功。本轮不认定公网持续稳定性已通过；灵感官网抓取遇到 robots、登录墙或限流时保留等待/失败说明，不补造分析。

浏览器 API 使用独立内存 PostgreSQL、真实迁移与真实 HTTP handlers；阻断外网并拦截所有网站 API，不触碰运行数据库、实际邮箱、收费模型或仓库。测试验证码、会话和邀请令牌不写进报告。
