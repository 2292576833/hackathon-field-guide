# 团队空间、首次登录与 DSH 站内检索验收

日期：2026-10-09。主会话集成，依据宪法 v1.9.0、规划 16–18。最新生产构建已完成并重启本机网站。

## 用户现在怎么用

首次登录会出现六步网站指引，介绍找比赛、个人准备、团队空间、任务协作、展示提交与复盘。完成状态按账号保存；中途可以稍后继续，账号页可以重看。接受邀请时先完成加入操作，再引导进入空间，所选比赛与原返回位置保留。

团队空间保留五个主要入口，工作台用六段、16 个节点的指引树串联：作品目标与邀请 → 比赛要求与官方赛道 → 职责、时间和计划 → 执行与交接 → 演示和正式提交 → 复盘与复用。默认展开依据实际记录建议的当前段，每项说明何时做、怎样做、怎样核对与下一步。其他段可自由展开，原阶段说明作为折叠补充。邀请入口在各空间页面顶部，树里的邀请链接也可以直接打开窗口。

导航员支持相关词检索，例如“链接邀请队友”“Git 冲突”“PPT 模板”。服务端先查本站可读资料，把真实短摘录和准确入口交给同一 DSH 回答；回答下方可以展开“本次找到的站内资料”。来源有实际更新时间时显示该时间，只有日期时保留日期，没有时间的功能说明不补造时间。没有命中、部分来源读取失败或内容尚未分析时有对应说明。当前账号、空间切换时清除上一处引用展示；刷新历史不会立即清除刚收到的来源链接。

## 资料范围与来源

| 来源 | 本轮实际接入 | 呈现边界 |
| --- | --- | --- |
| 本站原创资料 | 6 篇入门资料的正文与操作步骤 | 标为本站原创资料 |
| 网站功能说明 | 11 份明确编写的入口与操作说明 | 标为功能说明，不冒充外部权威文章 |
| 工具与资料 | 最多 100 个当前审核发布的资源快照 | 排除未发布、撤下及被阻断条目 |
| 比赛 | 最多 60 个已保存的 DSH 分析快照 | 保留未知、已截止与历史日期，标为未核验线索 |
| 技能 | 最多 100 个合法已发布固定版本 | 许可、兼容依据与真实客户端效果分别说明 |
| 灵感 | 最多 60 个当前官网候选及实际持久分析 | 待分析候选仅提供身份、链接及等待状态 |
| 当前空间 | 经权限校验的作品摘要和空间功能入口 | 不读取队友私人画像、测评、行程、讲稿或 PPT |

这是一份有界站内语料，不承诺收录所有文档、全网或全部历史记录。每次返回最多 6 个结果，检索结果 JSON 限制 12 KiB，摘录保留实际来源中的连续文字。内部开发文件、环境配置、审计记录与任意服务器路径不进入公开索引。站内查找不触发联网采集；用户明确发送问题后仍使用既有 DSH 模型预算。

来源文字与用户问题均按不可信内容处理，不能成为执行指令。链接由服务端限定，DSH 只能选择给定 ID。回答前重新检查账号、会话、项目权限和已引用资料；引用被撤下、发生修改、无法复核或空间摘要改变时，阻止旧答案返回并提示重新核对。未知模型请求保留账本 hold，不自动重发，不使用静态回答冒充 DSH。

## 本轮发现并修复

| 问题 | 最终调整与验证 |
| --- | --- |
| 创建空间后不清楚先做什么，多个“下一步”互相抢位置 | 工作台只保留树里的一个当前建议；目标缺失、读取失败和归档各自说明 |
| 手机树的嵌套边距太大 | 减少外层留白，375px 与 1280px 截图复核，无横向溢出 |
| 点击树内邀请链接只更新地址，未打开窗口 | 处理同空间锚点点击；真实点击、关闭、重复入口及权限回归通过 |
| JSONB 回读改变键顺序，计划确认被误判为冲突 | 按固定业务字段比较成员意愿引用；真实持久化确认及对应回归通过 |
| 计划生效后切换参赛阶段使同一计划失效 | 增加稳定项目事实版本；阶段变化不影响，目标、成员等实际变化仍要求复核，旧计划保守比较 |
| 保存规则后同页赛道仍显示没有规则 | 当前空间定向刷新；保留未保存输入，明确载入与确认才替换基线 |
| 无 GitHub 服务配置时新人没有下一步 | 保留图形教程、手动操作说明和返回当前空间的入口 |
| 私人计划、注册登录与展示页容易丢失比赛或空间 | 回跳与资料预览后确认带入的完整路径已验证 |
| DSH 调用期间来源变化可能返回旧建议 | 已引用公开资料及发送给模型的空间摘要均在最终权限事务复核 |

阶段标签、阅读指引、提交成果、队友检查、代码保存、运行记录和主办方提交分别保留事实。任务等待真实前置检查，讲稿大纲等可并行准备；没有新增树状勾选表或假完成百分比。
