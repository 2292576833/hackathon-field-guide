# 账号、专属参赛计划、路演与 PPT 验收

日期：2026-10-09。主会话已接收四个模块会话交付并完成集成。以下区分代码测试、真实模型验证和外部服务条件。

## 已实现

- 独立注册入口、邮箱验证码登录、昵称与个人参赛画像；验证码校验通过才创建账号。
- 每账号稳定的网站 DSH 工作台 ID、服务端聊天历史及私有成果，项目聊天另按权限隔离。原生 DSH 调用使用隔离子进程，不共享桌面私人会话。
- 赛事卡片进入专属计划，读取首次参赛、开发经验、城市、每日可用时间、项目想法等画像；生成五阶段任务、出行核对、路演准备、风险与备选，支持 Markdown 导出。
- 天气通过真实预报接口按城市和日期读取。缺城市、时间或参赛形式时支持本人补充，界面明确显示来源；远期、同名城市与失败均不补造预报。
- 路演页提供两个原创虚构练习案例、注意事项、计时讲稿、演示备选与问答，生成结果保存到当前账号。
- PPT 页提供三个原创框架、制作工具链接、真实 DSH 逐页大纲、Markdown 与打印预览。可以继承本人路演输入，当前不导出 `.pptx`。
- QQ SMTP 与 Resend 可选发信；SMTP 严格 TLS、单个收件人、总超时、实际连接取消、无自动重发。公开站点没有凭据时明确不可发送，不暴露开发验证码。

## 关键修复

- 个人生成期间复核会话、画像版本与成果所有者；跨账号不能读取结果。
- 未知模型请求保持预算预留和阻断；更换提示词、刷新页面、跨日不会解锁重放。
- DSH 退出等待区分进程退出和继承标准流未关闭，取消必须确认进程终止。
- 模型只提供需要的建议字段；额外日期、来源、身份、完成状态等元数据不采用。天气附加提醒中无法核实的文字会省略并标注。
- 任务验收条件作为未来目标检查，页面和导出明确不代表工作已完成；报名成功、资格保证、虚构金额或天气等仍拒绝。
- PPT 固定页数、时间、事实引用由服务器构造，模型只负责标题、讲解与视觉建议；仅有想法时不会声称已有演示成果。
- 修复从路演进入 PPT 的登录返回地址和超过十二条进展的完整继承。

## 仍需真实条件

- 用户确认没有可管理 DNS 的域名，并选择 QQ SMTP。主会话已保存用户提供的授权码并重启网站，当前邮件状态为 configured；向用户指定的管理员邮箱发起一次真实登录验证码发送，QQ SMTP 服务器已受理。收件箱实际到达及手机输入验证码完成登录仍待用户确认，不能等同为两项均通过。
