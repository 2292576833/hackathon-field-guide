# 新人主路径与信息简化

日期：2026-10-11。依据用户“项目给黑客松新手用，信息量得简化，点进去有一条明显路径知道该怎么做”“阅读整个项目”“写宪法，规划，分会话执行”，以及追加“受众群体是新手、选手，还有主办方”。对应宪法 v1.14.1。本轮复用已有功能和真实状态，减少理解和寻找入口的成本。

## 1. 完善后的想法

网站服务新手、选手和主办方三类使用场景。新人首先看到如何开始；已报名或已有经验的选手直接继续自己的比赛和团队任务；主办方从醒目的入驻入口进入办赛工作台。新人不新增权限角色，选手兼任主办方不必重新注册账号，实际功能仍按当前组织、比赛和权限开放。

| 使用场景 | 首个去向 | 当前重点 | 不应增加的负担 |
| --- | --- | --- | --- |
| 第一次参加黑客松 | 开始参赛指引 | 看懂报名、组队、任务、交作品的先后 | 强制先配置工具、填写完整画像或创建团队 |
| 正在参赛的选手 | 我的参赛／对应比赛／团队空间 | 继续当前任务，查看截止、通知和交接 | 每次重看教程或先浏览整站功能 |
| 主办方 | 主办方入驻／办赛工作台 | 发布报名、审核选手、发通知、管理赛程与收件评审 | 在选手工具中寻找办赛入口或另注册账号 |

首页按“开始指引、继续参赛、主办方办赛”标明三个去向；进入各工作区后突出本人的当前行动，不在每页重放身份选择。

选手主线：找比赛 → 核对要求和报名 → 准备并组队 → 确认作品目标与分工 → 做任务和交接 → 演示与正式提交 → 复盘。工具、教程、灵感、技能、GitHub、PPT、路演、出行是相应步骤中的辅助入口，不都是必走关卡。设计草图、讲稿大纲和素材可以并行准备。

公开参赛指引解释通用流程；我的参赛汇总本人的正式报名与私人空间；团队工作台依据原任务、计划、成员和交付事实给下一步。三者不再重复展示整站介绍，不增设一套勾选或完成百分比。

## 2. 当前证据与问题

- 已有公开树状路线图、首次登录分步引导、团队详细指引树、任务式工作台和按账号记忆的空间AI，不能当成从零建设。
- 首页与顶部主要引导仍偏多个工具入口，主办方入驻在页脚及较后位置，首屏没有明确的通用开始入口。
- 公开指引把节点及多个辅助资源同时展开，阅读量超过“当前一步”的需要。
- 我的参赛同时呈现空间创建、个人准备、账号资料、固定队伍等操作，新人需自己判断先后；创建和已有空间应有不同主要行动。
- 首次指引完成后，全站仍重复显示重看按钮；完整指南、AI详细内容和低频设置应按需出现，任务和真实阻塞保持可见。
- 实际各页面问题由本轮只读审查与交付继续补证，不以文档条目推断所有页面都已读或修改。

## 3. 本轮实施

### P01 首页、全站导航与指引入口（主会话）

顶部保留少量明确入口，增加醒目的主办方入驻按钮。新增参赛指引入口，找队友继续在相关准备场景直达，不删除原地址。首页突出开始指引，说明已有空间如何继续；主办方入口同时有简短办赛说明。已完成指引的重看入口移入账号操作，邀请、报名的原去向不变。

### P02 公开参赛树（公开体验会话）

保留起点—阶段—行动—资源的树状关系和原有直达。行动说明短而具体，辅助资源默认收起，展开能看到用途和真实链接。当前主要开始动作明显；不从浏览指南推断个人进度，不新增付费调用或登录前置。

### P03 我的参赛与团队工作台（空间体验会话）

区分未登录、无空间、有空间、已存在任务等情形。主操作就地开始或继续，个人准备、固定队伍、长指引、历史和设置按需展开。保留常驻邀请、当前任务/等待交接/阻塞、明确共享后的团队动态和独立私人AI。下一步来自已有真实记录或清楚标明的通用建议，未知状态保留；不能只凭项目阶段宣称已报名或已完成。

### P04 根接入与验收（主会话）

复核公开/私人/主办方/评委边界、旧地址、登录返回和必要上下文。合并交付后执行整站类型与生产构建，检查320/390px和桌面主要入口、折叠与键盘焦点。只改展示不要求新增数据库迁移，不为低影响样式制造镜像测试；现有有意义的行为检查适用时执行。

### P05 展示材料与就地名片（空间体验会话追加）

路演/PPT优先显示本人的项目来源、模板选择和编辑工作区；案例、模板逐页说明和工具资料按需展开。保留私有保存、DSH生成、未知请求恢复和明确分享规则。找队友页的“准备我的名片”就地打开已有编辑器，避免同一功能反复跳账号页。规则页和排程编辑仍保留当前结构，本轮只读审查记录后续降低长表单负担的建议，不更改业务确认流程。

## 4. 信息保留规则

首屏：当前空间/比赛/身份、现在要做什么、一个主要按钮、重要截止和明确阻塞。第二层：任务/队友/官方通知及实际记录。第三层：教程工具、完整指引、AI详细解释、高级设置和历史。

不得折叠到看不到错误、未保存输入、必须核对的资格/费用/截止/共享范围/正式发布确认。收起不会删除记录，打开详情不发模型请求，AI生成/共享/报名/提交仍须用户明确操作。正式赛事名单与私人团队空间保持区别。

## 5. 验收

- 新人从首页能明确开始；已报名或已有空间者能直接继续，主办方入驻无需滚到底部寻找。
- 无空间时不同时出现多个同等强度的创建/准备按钮；已有空间不被创建表单压住。
- 指引资源默认按需展开，完整树、注意事项、教程、旧路由和原权限仍可达。
- 当前任务、交接、失败恢复、归档只读、邀请与本人空间AI可用；不伪造状态。
- 登录/首次指引保留原目的地，完成后仍可从账号重看；手机没有主要操作横向溢出。
- 文档、源码、隔离测试、本机部署、域名与手机结果分别登记。新域名解析异常独立处理，固定节点TLS成功不代表手机通过。

## 6. Constitution Check

I/X：真实参赛步骤与一个主要行动；II：依据和未知状态保留；III/IV：不改变分工、依赖与进度；V/VI/XI：不改变GitHub、私人空间和主办方权限；VII：复用原组件与原路由；VIII/IX：检查错误恢复、手机和外部网络，禁止虚假成功。本轮不新增业务数据库、角色或模型工具。
