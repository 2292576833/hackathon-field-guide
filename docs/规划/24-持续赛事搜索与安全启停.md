# 持续赛事搜索与安全启停

2026-10-11 用户要求 DSH 每天持续搜索分析赛事至少 5 小时，并明确保持赛事发现每日 1 美元上限。域名工作按用户要求暂停。

## 调度与费用

- 服务器运行时，每 10 秒检查持久账本；两轮之间至少 5 分钟，网页刷新不触发付费调用。
- 本机每轮一个原生搜索词，最多读取分析三页。16 个关键词批次覆盖官网、微信公众号和公开社交平台索引，随当前月份更新，重启按账本调用次数继续轮换。
- 每 UTC 日最多 144 次搜索、360 次模型调用，赛事搜索和分析合计预算 1,000,000 microUSD，即 1 美元。次数上限不代表实际会调用这么多次。
- 5 小时是持续运行目标，不覆盖费用、来源可达性和未知请求保护。达到费用上限、下一轮预留不足或请求结果未知时停止相应付费请求，显示原因。用量缺失按完整预留计入；未知请求 hold 不清除、不跨日重放。
- 本机当前每轮保守预留 366,183 microUSD。供应商真实用量返回时按原账本结算；不能为达到时长而降低未经验证的最大上下文预留。
- 不保证搜索到全部平台、小程序内部页面或所有比赛。网页展示真实保存的分析、来源链接和未核验说明，不造卡片或通过日期隐藏原结果。
- 单页面上限需要按持久轮次交替给新搜索结果和旧卡复查位置，不能让旧卡永远占据唯一分析槽。多页面既有排序保留；同地址合并本轮真实引用，不用旧卡摘要代替证据。
- 默认原生关键词轮换遇到未知搜索 hold 时，以真实 provider 的相同请求身份和关键词哈希，只读选择下一个未冻结的独立批次。冻结请求仍由账本保留，不能清除、假增付费次数、修改身份或随机加盐来绕过；所有批次冻结时明确暂停搜索并要求管理员处理。自定义固定关键词不擅自替换，真正发出请求前仍由原事务 claim 复核。
- 仅在公开IP、TLS与实际连接核验后，robots.txt的真实404/410可按既有缺失文件规则处理，错误HTML正文不作机器人指令；200正文、其它路径和响应大小限制不放宽。

## 真实统计

新增迁移 055，仅保存已返回搜索或已读取页面的轮次观察，不修改付费账本。每轮 UUID 去重；轮次回执与每日累计同事务写入，记录失败不重跑搜索。

管理员控制台显示目标小时数、已处理轮次、已返回搜索、读取页面、保存卡片、各轮累计处理耗时和首次至最近一轮的跨度。累计耗时含网络/模型等待，但不含轮次间隔；跨度包含间隔、可能的停机，不能算成纯 DSH 忙碌时长。不补造历史统计，不凭时钟流逝标记“已完成五小时”。

## 安全启停与管理员测试

Windows 强制结束进程不能保证嵌入式数据库正常写回。新增受限本机文件控制：启动实例随机密钥与标识，停止命令提交签名请求；拒绝新 API 请求，等已接受请求和后台任务结束，然后正常关闭数据库、签名确认并退出。没有公开停止接口，不将控制密钥发到网页。

使用 `npm run server:stop` 或 `scripts/serve-service.ps1 stop`；失败不强杀，未确认关闭前不能同时打开生产数据库或进行冷备。成功后仍须核对没有自动重启或其他数据库拥有者。

管理员测试仅为已有活跃且邮箱已验证的管理员签发原登录体系的一次性验证码。凭据写到受限本机文件，十分钟有效，首次使用后失效；测试入口不自动创建用户或赋权。公开网站保留安全 Cookie，本机 localhost 的测试 Cookie 单独使用。

## 验收边界

必须区分源码、隔离测试、真实迁移、运行配置、真实搜索和全天观察。短时间验收不能宣称五小时实际运行已经完成；最终报告记录停机恢复、迁移、构建和实际启停结果。
