# 28 · 团队空间协作视图与画布重设计

日期：2026-10-12。用户授权：根据当前团队空间重新设计、找出问题、完善规划与宪法并分会话执行。继承规划27已经实现的组件、私人画布偏好与现有权限；本轮不重建任务、账号或正式提交体系。

## 1. 当前问题与证据

| 问题 | 源码证据 | 对用户的影响 |
| --- | --- | --- |
| 手机沿用宽画布 | `space-canvas-board.module.css` 的画布最小宽度1600、默认主线x=280 | 手机首屏看不全主要操作，必须横移找内容 |
| 滚动等于调整尺寸 | 画布wheel监听对组件内容无条件preventDefault并PUT布局 | 阅读长文时改尺寸、频繁请求和版本冲突 |
| 触屏与文字选择被拖动抢走 | 卡片本体touch-action:none、user-select:none | 手机难滚动，正文难复制 |
| 基本操作只藏在右键 | 仅contextmenu提供折叠/移除 | 新人、键盘和触屏用户难发现 |
| 默认内容不足，身份不明 | 默认仅放主线；缺少常驻空间名称和邀请入口 | 不清楚在哪个空间、现在做什么、如何拉队友 |
| 两层画布尺寸不匹配 | 外卡380宽，流程内画布约1180宽 | 内容越界并与新组件重叠 |
| 来源未读取被当成完成 | 主线stepState只排除prepare/check | loading/error/unknown也显示已完成 |
| 桌面节点不能键盘打开 | 节点只有pointer事件 | Enter/Space无法完成核心导航 |
| 时间表单与真实接口不一致 | 主线PUT只送effectiveMinutes；真实接口要求windows/timezone/本人revision | 用户填写时间后保存失败 |
| 共享编辑假成功 | 文档UPDATE仍限定author_id为当前操作者 | 队友编辑0行也返回成功 |
| 文档只读内容被截断 | 只读正文仅显示前320字 | 队友不能读完整交接资料 |
| 助手依赖被移除的卡片 | fixed入口置于transform卡片内 | 位置错乱；移除卡片丢失助手入口 |

以上区分源码确证与待浏览器验证；不能用历史测试次数证明新人已经完整走通。

## 2. 设计目标

首屏回答：**这是哪个空间、我现在做什么、谁在等谁、下一步去哪**。保留用户选择的自由画布，提供默认协作视图；布局编辑不能抢走日常使用。

### 默认协作视图

1. 紧凑顶部：返回我的参赛、空间名称、当前身份、邀请队友、空间AI入口、视图切换。
2. 当前工作：我的待办（本人）与团队四态总览（共享事实）。
3. 清楚的单向步骤：目标 → 比赛要求 → 分工时间 → 做任务 → 演示提交 → 复盘。任意节点可打开，顺序不锁死并行任务。
4. 队友状态与空间文档就地阅读；倒计时和范围调整作为按需展开的辅助内容。
5. 单人同样可用；没有计划、读取失败、归档只读分别解释，不显示虚构完成或百分比。

### 自由画布

- 保留旧布局与私人坐标、尺寸和缩放，不自动清空或改写。
- 浏览状态允许正常滚动、选择、复制和点击；点击“调整布局”才开放拖动与调整。
- 布局调整只从明确抓手开始；提供可见的折叠/移除/尺寸入口与键盘等价操作；右键是辅助入口。
- 普通滚轮始终用于阅读；可选Alt+滚轮只在布局调整模式使用，不能误改输入框/弹窗。
- 手机始终按内容单列流式展示，不保存桌面坐标变更；退出手机后仍保留原桌面排布。
- 摆放是本人偏好；任务、共享文档与检查事实仍来自全队同一份数据。

## 3. 业务与权限

- 团队进度只计当前空间、当前已生效计划和有效检查记录；done字样不等于检查通过，取消任务不算完成。
- 计划过期或读取失败时不给过时数字和“全部完成”；红色仅用于真实阻塞/待检查，规则变化显示复核提示。
- 页面可定期只读刷新任务快照，隐藏标签暂停；刷新不触发DSH、生成、共享或提交。
- 文档所有成员可读；作者显式开启teamEditable后队友才可编辑；版本冲突不覆盖，UPDATE必须影响实际记录才成功。
- 归档空间保留文档/待办读取，阻止新业务写入；私人画布偏好不改变归档事实。
- 文档全文直接可读；“记入我的待办”明确创建本人私人备忘，标记它不改变团队任务或已读状态。
- 用户追加：文档像TXT直接展示连续全文，默认全宽，不加正文卡框、折叠阅读、固定高度或内部滚动遮挡；编辑框随文本增长，手机自动换行。简洁工具栏保留复制、编辑与权限操作。
- 本人AI对话不自动共享；空间AI唯一稳定入口独立于画布卡片。导航员与空间AI分别说明用途。
- 可见旧组件锚点保留，跨成员链接不能暗示分享了私人待办正文。

## 5. 验收

1. 375px手机首屏可见空间名称、邀请/权限提示、当前动作；正常滑动，不横向滚整页。
2. 默认协作视图无需添加组件就能看到本人待办、团队概览与流程。
3. 普通wheel不会发出布局PUT；调整模式的保存串行/受控，版本冲突保留输入与恢复入口。
4. 核心节点用鼠标和Enter/Space均可打开；移动端折叠/移除有可见按钮。
5. 实际windows/timezone/revision保存本人时间；错误输入留在原表，归档不可写。
6. 共享文档队友编辑后重读得到相同正文；未共享编辑/外部成员/归档写入拒绝，过时版本409。
7. 读取中/失败/未知不显示完成；done无检查不计完成；取消和外空间任务排除。
8. 旧自由画布偏好仍可读，切换视图和手机展示不改业务状态与桌面坐标。
9. 定向测试、类型检查、生产构建与追踪清理通过，再冷停并启动新版；公网/实体手机结果另记。
