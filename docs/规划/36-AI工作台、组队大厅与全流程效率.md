## 2. 想法清单

### 2.1 AI 工作台（整页，替代浮标）

点入口，整页变成 AI 工作台：**左侧网站入口 + AI 工作情况、中间对话、底部输入**，与 DSH 同构。

**左侧两块**：
1. **网站入口**——按「参与 / 主办 / 平台」分组的直达链接，替代「回导航再找」；
2. **AI 工作情况**——每个助手一行：`待命 / 正在读资料 / 已出草稿 / 不可用（未配置模型）`，并显示它这次读了哪些事实来源（只显示名称，不显示内容）。

**中间是讨论区**：用户说一句 → 编排器（代码）决定叫哪几个专员 → 每个专员各出一条**发言卡**（角色 + 1–2 句 + 依据）→ 导航员做**总结**：一个方案 + 2–3 条建议 + 一个待确认动作。

- **这是编排，不是模型互调**：传输层是单次 JSON、提示词明令不得调用工具，所以「AI 与 AI 讨论」由代码按顺序发起，界面按发言展示；
- 每轮**最多 3 个专员 + 1 次总结**（4 次调用封顶），可随时停止；
- 专员失败或未配置时显示「未参与」，**不编造它的发言**；
- 总结里每条建议必须写明**出自哪位专员**；
- 输出永远是「方案 + 建议 + 按钮」，人不点不生效。

**边界**：讨论内容只含当前身份有权看到的事实；不跨机构；不公开；AI 仍不执行、不改状态。

**硬边界**：会话只含当前身份有权看到的事实；不跨机构；不公开；AI 仍不执行、不改状态。

### 2.2 选手端主 AI + 表单步骤指引

遇到要填的东西，**直接出步骤卡**：第 1/3 步、这一屏填哪几栏、每栏一句人话。

- P1：说出「该填这三栏」，点按钮跳到真实表单页并**高亮/聚焦**；
- P2：对话框内**内联步骤卡**，AI 预填能推出的值，用户确认后写进表单草稿；
- **字段来自平台表单定义，AI 只决定分几步、每栏怎么说、能预填什么**——不许发明字段；
- **AI 不提交**；AI 拟的句子标「AI 拟稿」。

### 2.3 AI 智能组队大厅

按简介与擅长推荐互补的队友/队伍；单独入口，**报名通过才可见**；也能作为组件嵌进主办方专属页。

- 复用参赛名片与 gap.ts，不建第二份资料；
- 三条门槛：已通过报名 + 名片已发布 + **本人主动开启愿意被组队**；
- 只给「角色 + 事实理由」，**不给分、不排名**；
- 接触走招募申请，不新开私信通道；
- 范围本场；主办方可配：是否开启、显示哪些字段、语气（封闭选项，不开放颜色/CSS）；
- 嵌入形态：专属页新增**动作块**「进入组队大厅」（跳转，符合动作必须跳转）。

### 2.4 主办方「今日待办」

一张卡：事实 + 一句话 + 一个按钮。下一步由**确定性规则**算（发布门槛、待审报名、评审轮、结果、专属页），AI 只解释并**一键起草**。

### 2.5 全流程效率

| 项 | 内容 |
| --- | --- |
| 全局命令面板 ⌘K | 跳页面、找比赛、找队伍、找助手 |
| 入口收敛 | 找比赛 6 → 1；团队 4 → 一个页面四页签 |

| 赛后路径 | 结果 → 申诉 → 复盘 → 资源 |

## 4. 明确不做

- AI 自主执行（不发布、不发信、不改状态、不代提交）；
- AI 评分/排名/晋级/推荐分；
- agent-to-agent 工具互调（传输单次 JSON，提示词禁工具）；
- 自定义 CSS/主题编辑器；
- 跨机构会话；公开聊天记录。
