# 规划 37 · 插件接入（MCP）与多模型厂商中立

> 日期：2026-10-18 ｜ 依据：用户要求「打包成插件让 vibecoding 软件直接访问网站与网站 AI；必须先注册才能拿到可用配置」＋「所有模型厂商都能装入」＋ 宪法 v1.25.0（拟）。
> 范围：**B 口径**（只读查询 + `ask_specialist`）。不含任何写入型工具。

## 1. 目标与不做什么

**目标**：用户在自己常用的编码工具（DSH / Claude Code / Cursor / Cline 等）里，直接查本站赛事、报名、组队大厅、材料状态，并能向 12 个专员提问。

**不做**：
- 不提供提交、发布、改状态、发信、评分类工具；
- 不在插件包里内置任何密钥；
- 不为每个 IDE 单独开发（统一走 MCP）。

## 2. 形态

```
用户 IDE ──MCP(stdio 或 Streamable HTTP)──► hfg-mcp ──HTTPS + PAT──► 本站 /api/v1
```

- **第一版：stdio**，`npx @hackathon-field-guide/mcp`，配置里只放 token；
- **第二版：HTTP `/mcp`**，供只能接远程 MCP 的客户端。

## 3. 工具面（封闭清单）

| 工具 | 入参 | 出参 | 权限 |
| --- | --- | --- | --- |
| `find_events` | `query?`, `limit?` | 公开赛事卡片 | `events:read` |
| `my_registrations` | — | 我的报名与状态 | `me:read` |
| `team_hall` | `eventId` | 愿意组队的人（名片公开字段） | `hall:read` |
| `submission_status` | `eventId` | 是否已交、缺件 | `me:read` |
| `site_search` | `query` | 站内资料 | `events:read` |
| `ask_specialist` | `eventId`, `key`, `instruction` | 专员草稿 + 读了什么 | `ai:ask` |

**边界（写死）**：`ask_specialist` 只返回草稿；所有工具只读；不提供任何写操作。

## 4. 账号与令牌

1. 本站注册 + 登录 → 「设置 → 接入令牌」；
2. 生成 PAT：`hfg_` 前缀、命名、可选过期（默认 90 天）、scope 勾选（默认全选只读 + 可选 `ai:ask`）；
3. **只在生成时显示一次**，服务端只存 `sha256`；
4. 撤销即时生效；记录 `last_used_at` 与调用次数；
5. 页面给出**一键复制**的安装命令与各客户端配置片段；
6. 进阶（第二版）：OAuth 设备码，`npx hfg-mcp login`。

## 5. 服务端改动

- 迁移：`mcp_tokens(id, user_id, name, scope, token_hash, expires_at, revoked_at, last_used_at, created_at)`；
- 鉴权：`Authorization: Bearer hfg_...` 与既有 cookie 会话并列，同一 `Actor`；
- 限流：每令牌 60 次/分钟、每日 `ai:ask` 上限（默认 50）；
- 审计：每次调用写 `mcp_call`（工具名、令牌 id、耗时、结果码，不含正文）；
- 复用：所有工具**只调既有服务**，不新增读取路径。

## 6. 多模型厂商中立

- 统一端口 `JsonModelPort`（已存在），厂商适配层为**数据**（baseUrl + 密钥来源 + 计价 + 能力），不是分支代码；
- 支持：DeepSeek（DSH 桌面账号 / API Key）、OpenAI 兼容（含 vLLM、Ollama 等本地）、Anthropic；
- 密钥：只从服务端环境或加密凭据库读取，**不入库明文、不进响应、不进日志**；
- 计价：每厂商独立 `input/output` 单价与每日额度；未计价时**不得扣费**且不得静默重放；
- 失败语义：厂商不可用 → 明确 `AI_UNAVAILABLE` + 降级提示，人工流程照常；**不自动换厂商重试**（会造成重复计费与不可审计）；
- 切换厂商不改产品语义：AI 仍只出草稿、不执行、不判分。

## 7. 分期

| 期 | 内容 | 验收 |
| --- | --- | --- |
| P1 | 令牌表 + PAT 生成/撤销 + 设置页 | 401/403/撤销生效/哈希存储 |
| P2 | stdio MCP 包（5 个只读工具） | 三个客户端各跑通一次 |
| P3 | `ask_specialist` + 限流 + 审计 | 额度耗尽有明确错误 |
| P4 | HTTP `/mcp` | 远程客户端可用 |
| P5 | 设备码登录 | 无需手填 token |
| P6 | 厂商中立配置页 | 至少两家厂商可切换并各自计价 |
