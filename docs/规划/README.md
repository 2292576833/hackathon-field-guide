## 当前实施与试用顺序

本机先用开发邮箱预览完成登录，运行项目、分工、计划、交付记录和复盘流程。赛事与策展资源通过运营审核发布；原创 `/library` 入门说明可以直接阅读。技能安装先核对固定版本、许可与文件清单，再明确连接本人本机项目。

准备真实试用时，按部署说明配置 PostgreSQL、邮件、通用 AI、DSH、Brave 和 GitHub App，再验证后台持续运行、真实发送/调用/写入和容器状态。DSH 位于后端，不要求参赛者自行安装 DSH；M10 桥接安装的是用户选择的参赛技能。

发现卡片与已审核赛事分别呈现；搜索查询、robots、预算和可访问页面限定覆盖，不承诺完整全网。未配置、未核验、结果未知、文件写入及客户端任务验证必须按实际状态展示。

使用一场真实比赛和少量试用队伍检查可用性，再依据效果和费用扩大范围。验证状态以 [验收报告](../协作/验收报告-2026-10-08.md) 为准；本入口不把代码测试或目录适配等同于真实第三方与客户端验收。
