# O01 入驻与赛事核心

日期2026-10-11；遵循规划21、宪法v1.11.0与公共organizer-contracts。独占新 src/modules/organizer/ 和 docs/协作/交付/organizer.md。不改root/shared/app/server/migrations/依赖，不 build/重启/开实际DB。根授权本模块可在新目录实现客户端组件与 CSS，复用已有通用 api/SiteShell/Field。

## 目标与流程

主办方申请→查看待审核/补充/结果→人工admin审核→选机构→选模板建赛→预览→发布→查看自己有权限的比赛。一个账号可管理多组织、多比赛，不给全球主办方管理员角色。

## 实施任务

1. 模型 Organization/application/staff grant/HostedEvent/published revision/template，明确组织与赛事权限。申请证明首版支持受控文字说明/HTTPS依据链接；上传凭证为本机受保护大小/MIME限定附件或明确暂不提供，不抓取任意内网URL。
2. 服务申请、本人申请读取、admin审批、组织读写、staff授权/撤销、建赛/编辑/预览/发布/归档与公开列表、本人权限赛事列表。每个mutation事务复核当前账号、guard、当前权限与expectedRevision；组织批准不代表赛事质量保证。
3. Postgres持久适配/SQL建议，不生产内存目录。使用auth_users FK；组织/赛事ID作为关系条件，角色不能由客户端自报。公开投影剔除联系人/证明/私密配置。
4. 提供公共 HostedEventAccessPort 完整实现：getEvent、requireStaff；按当前组织审核/停用和grant再判断，revoked禁止继续写/导出。
5. 模板常用默认，配置modules仅固定白名单；线上/线下/练习赛三种，时间带时区。高级设置折叠，表单不要求JSON；常用字段上下移动。报名字段的具体验证由O02，评分维度由O04，不通过任意模板JSON获得代码执行权。
6. 前端 OrganizerEntry、OrganizerWorkspace、CompetitionDirectory/CompetitionOverview、AdminOrganizationReview 导出ui.ts。可预览规则与发布范围，保留输入与中文恢复提示。
7. index.ts/README/API登记/NEEDS_INTERFACE/关键node:test/交付。

## 字段与规则

HostedEventScope公共字段及module开关遵循src/shared/organizer-contracts.ts，不私自换命名。Event ID与旧M03 ID不同，linkedEventId可空，仅根控制关联。首次published生成不可变snapshot版本；更改规则形成新版，不能改历史。审核机构停用后公开入口按状态提示与当前操作限制造成真实判断，不自动删除报名/评分。

组织管理员只获得组织管理与所属赛事运营能力，不读取M02私人资料；评委必须O04明确指派。平台admin仅机构审查，不默认遍历私人参赛材料。组织角色不能从平台 reviewer继承。grant作用域 organization-wide 或 event-specific +固定capabilities，事件组织匹配。

## HTTP建议

GET/POST /organizer/applications；GET /organizer/applications/mine；GET /admin/organizer/applications；POST /admin/organizer/applications/:id/review。
GET /organizer/organizations；GET/POST /organizer/organizations/:organizationId/events。
GET/PATCH /organizer/events/:eventId；POST /organizer/events/:eventId/publish、archive。
POST /organizer/organizations/:organizationId/staff-grants；POST /organizer/staff-grants/:id/revoke。
GET /competitions；GET /competitions/:eventId；GET /me/competition-identities。
根最终统一HTTP路径，提交时精确登记factory方法/body/返回字段。

## 验收

跨组织/跨赛事角色矩阵；机构自审拒绝；撤权后缓存/写入拒绝；配置revision冲突不覆盖；public无PII；同时多比赛；模板默认/无模块入口；无登录公开规则；mutation有当前guard。单独模块测试不等于根实际上线。
