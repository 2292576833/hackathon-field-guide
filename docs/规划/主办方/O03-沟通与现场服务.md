# O03 沟通与现场服务

日期2026-10-11；规划21、宪法v1.11.0。独占新 src/modules/event-communication/ 与 docs/协作/交付/event-communication.md。不改公共/根/依赖，不真实发邮件/短信、不build/开实际DB。

## 目标

主办方与选手共用正确赛事沟通区。官方通知、公开问答、私人求助、行程和本人现场服务放在对应比赛中，不另建无范围微信式聊天群，不让选手翻大表找自己。

## 实施任务

1. 官方Announcement版本发布/撤回/当前版本read receipt；重要更新旧已读失效，站内已读不等邮件投递。可从窗口查看通知依据，草稿不是官方规则。
2. HelpTicket公开问题/私人求助，状态open/in_progress/answered/closed；本人发问/追加、专责communication_manage答复。公开FAQ只在原作者确认预览后发布，不自动公开私人ticket。回执/修改人/更新时间保留。
3. Schedule不可变发布版本、时区/地点/适用范围；主办输入结构化条目或先CSV预览校验再确认，不能上传附件即称自动理解/已发布。选手仅看发布且适用本人条目。
4. 破冰可选activity/voluntary participation/manualgroups记录，用户拒绝不影响参赛资格；自动配对未真实实现前不宣称成功。
5. 住宿人工assignment/导入预览/确认/更正版本，限本人及logistics_manage，过度个人信息不收集，整张住宿表不能公开。上传表格完成与分配确认分别记录。
6. 餐券type/issue/ownlist/redeem，opaque随机token可注入密码安全生成；存token hash，不打印token/二维码传第三方。stafflogistics授权、事件范围、过期、撤销、并发重复核销同事务；人工核销会留下操作员回执。不宣称接酒店/支付。
7. 前端 EventCommunicationPanel、CommunicationManager、EventSchedulePanel、OwnEventServices、LogisticsManager 导出ui.ts。按moduleflags隐藏关闭的现场能力，入口直达待回复ticket；手机主动作易触达。
8. Postgres适配/SQL/index/README/API/NEEDS_INTERFACE与关键测试。邮件出站以rootNotificationPort契约登记，不加SMTP依赖、无默认真实发送。Port未注入仅站内明确提示。

## 权限与集成

使用EventAccessPort的communication_manage/schedule_manage/logistics_manage和EventParticipationPort检查本人报名状态。公开发布内容可读但不给私人ticket/住宿/券数据。工作区后台必须按eventId查询和导出，不能因机构相同跨赛读取不同专员数据。

DSH客服只可用公开官方FAQ或此ticket已授权内容，回答需标明来源/未知；AI草稿不自动变官方答复。真实自由对话由根已有DSH组合，当前模块人工闭环即可，不返回假的AI回复。

## HTTP建议

GET /competitions/:eventId/announcements；POST announcements/:id/read。
GET/POST /competitions/:eventId/help-tickets；GET/POST help-tickets/:id/replies；POST publish-consent。
GET/POST /organizer/events/:eventId/announcements；PATCH ticket/:id/status。
GET /competitions/:eventId/schedule；PUT/POST /organizer/events/:eventId/schedule/draft、publish。
GET /competitions/:eventId/my-services；POST /organizer/events/:eventId/accommodation-assignments、meal-vouchers、meal-vouchers/redeem、icebreakers。
无需一次建所有根路由，精确工厂接口在交付登记。

## 验收

猜ticketId/跨赛事/private缓存/撤权均拒绝；原作者未同意不能公开；通知新版未读；未报名不看个人服务；行程时间校验/版本冲突；住宿本人隔离；券一人多type、tokenhash/无PII、最后次核销并发/重试。
