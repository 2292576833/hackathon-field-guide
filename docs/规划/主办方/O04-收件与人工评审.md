# O04 收件与人工评审

日期2026-10-11；规划21、宪法v1.11.0。独占新 src/modules/event-judging/ 与 docs/协作/交付/event-judging.md；不改M06/shared/app/server/实际迁移/依赖，不build/重启/真实外部提交。

## 目标

选手确认正式材料→主办方收到不可变快照与回执→无冲突的指定评委人工评分→负责人确认公布→选手只见允许公开的本人结果。保存/运行/收件/评分/获奖分别真实记录。

## 实施任务

1. IntakeSnapshot/Receipt 服务预览/submit/get own/get staff。材料首版bounded文字/HTTPS链接/metadata，URL不下载或执行代码；需要文件上传时由根受控存储，不放任意宿主路径。receipt含event/team/author/time/configRevision/materialhash/version/编号。
2. 同事务get EventScope、EventParticipationPort队伍/报名状态、确认队长或明确submit grant、作品截止和名单锁定、幂等键绑定input。重复同input同key同receipt，不同input拒绝；版本历史不可覆盖。
3. root VerifiedSubmissionPort可注入并使用同SqlExecutor，映射M03事件/阶段与M02项目时才同步M06；缺关联可正式收到独立参赛作品，但不得显示既有私人项目已platform_verified。不直接写M06表。
4. 标准维度/权重100%/范围/minjudges、轮次setup/open/locked/published；配置在开始后锁定，字段和missing/tie政策明示。评分按真人输入，系统确定性加权；缺评不是0，不自动AI评分。
5. JudgeAssignment/ConflictDeclaration/service检查：指定评委可读该正式快照，系统内参与关系由注入ConflictPort判断 + 评委主动申报 + 工作人员回避记录，实际不可判定显示needs_review并不自动授予。排除队伍成员、本站已知辅导，不能声称检测线下全部关系。
6. score draft/save/submit/lock/纠正审计；修改已有分数保留原记录、说明、轮次与权限。负责人可分配但不能作为未指派评委代打；权重与标准冻结。
7. result preview/人工publish/version/withdraw，批准score反馈公开范围。组织管理员没有默认私人助手资料读取能力。导出仅judging_manage，公式防注入。
8. 前端 EventSubmissionPanel、JudgeWorkspace、JudgingManager、EventResultsPanel 导出ui.ts；评委优先原材料，摘要未来按需显示，不诱导AI绝对分。公布前选手看到待评审/待公布，不伪造排行榜。
9. SQL建议/Postgres/index/README/API/Port测试与交付。AI摘要adapter契约只收submission snapshot和已发布rules；不导入participant个人画像、team-assistant或navigation。没隔离真实adapter时保持人工功能，不冒充分析完成。

## HTTP建议

POST /competitions/:eventId/submissions/preview、submit；GET /competitions/:eventId/my-submissions。
GET/PUT /organizer/events/:eventId/judging/config；POST rounds/start、lock、results/preview、publish。
POST /organizer/events/:eventId/judge-assignments；POST assignments/:id/revoke。
GET /judging/:eventId/assignments；GET assignments/:id/materials；POST assignments/:id/conflicts、scores/draft、scores/submit。
GET /competitions/:eventId/results（仅公布投影/本人反馈）。
根最终组合路径，工厂接口交付登记。

## 验收

跨租户/赛/队收件拒绝；作品过期及名单变更；同幂等键不同input；receipt不可变/链接不冒运行；未指派/撤回/回避评委读写拒绝；已known团队成员冲突；草稿与提交/锁定分开；权重/范围/缺评/同分；发布人工权限；private数据不进AI或publiccache；M06单一参赛提交事实。
