## 2. 多轮次评审（O04 范围扩展）

真实赛制普遍是**初赛 → 决赛 → 人气投票**，而现有 O04 是单轮"提交—评分—公布"。需要评估的扩展点：

- **轮次**：一轮赛事可有多个评审轮，各轮有**各自的材料范围、截止、评委指派与评分维度**；
- **晋级**：一轮结果决定进入下一轮的作品/队伍；晋级由**人工确认发布**，不自动产生；
- **人气投票**：与评委评分是**不同性质的事实**，必须分开展示与分开发布，不得合并成单一总分；
- **材料差异**：初赛可能只交提案，决赛交可运行作品；快照与回执按轮次分别冻结；
- **回避与冲突**：跨轮重新指派评委，回避关系按轮次复核。

**硬性约束**

- 每一轮的评分标准、权重与评委范围在**该轮开始前**校验并冻结（沿用现有规则）；
- **不自动决定录取/晋级/获奖**，全部由有权负责人确认发布；
- 人气投票与专家评分**不合并为单一排名**，除非主办方明确要求且明示计算方式与依据；
- 未评分不等于 0 分；缺评、回避、撤销指派在结果页面清楚显示；
- 已有单轮赛事的评分与发布事实**不得被迁移破坏**，扩展必须兼容既有数据。

## 3. 验收方向

- 多轮赛事可以配置并在每一轮独立收件、指派与评分；
- 晋级必须人工发布，且发布前的材料与标准处于冻结状态；
- 人气投票与专家评分分别展示，不合并成单一分数；
- 跨轮指派与回避按轮次复核；撤权后不可读不可写；
- 单轮赛事（既有数据）在新模型下仍可读、可发布，历史不被改写；
- 手机端能看到当前轮次、我的任务与截止。
