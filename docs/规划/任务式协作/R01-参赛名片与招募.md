# R01 参赛名片与招募

依据规划19与宪法v1.10.0。仅负责 `src/modules/recruiting/` 和 `docs/协作/交付/recruiting.md`，提供SQL建议、注入Port、完整前端组件、测试、index和README。不得修改app/server/shared/根迁移。

功能：私人主要/辅助职责、个人参赛目的、短简历、作品链接、选填MBTI/年龄/头像；独立公开名片快照及撤回；公开筛选；本人明确DSH归纳名片预览；活跃管理员发布招募帖、成员申请/撤回、管理员审核、申请人明确加入。无公开邮箱、无能力百分比，不从头像/年龄/MBTI推断能力。旧ParticipantProfile通过注入读取，不重写已有画像字段。

服务统一数据库事务、FreshSessionGuard、活跃账号，公开列表只投影已发布内容，身份/来源/更新时间由服务器固定。画像版本、公开修订、招募与申请有CAS；陌生人仅看到发布快照，退出/归档空间不能批准或加入。头像格式与大小严格验证，公开头像必须复核发布状态，私人编辑不自动覆盖发布图。

建议路由（由根组合）：GET/PATCH `/me/recruiting-profile`，POST `/me/recruiting-profile/summary`，POST `/me/recruiting-card/publish`，POST `/me/recruiting-card/withdraw`，GET `/recruiting/cards`、头像；GET `/recruiting/posts`、POST `/projects/:id/recruiting-post`、PATCH帖子；POST `/recruiting/posts/:id/applications`，GET `/me/recruiting-applications`/管理员列表，POST review/withdraw/join。用真实接口的模块UI可直接组合进账号页与新大厅，低频字段折叠。

需要的Port在交付NEEDS_INTERFACE给出准确签名：读取本人Participant资料；读取活跃空间且确认管理员/归档；DSH归纳（根个人AI预算与持久记录）；批准后明确加入（根M02，同事务、只授member）。公开帖子只用作者明确输入的描述，不自动读出私人目标。审批事实并不自动加入，join时复核审批与批准者仍有管理权。

测试：权限/非公开/公开撤回/私人编辑不污染公开/CAS/头像/不同账号隔离/申请幂等与加入/AI结果不自动发布。无真实网络或生产数据。收到根通知后交付停止，根统一接入与验收。
