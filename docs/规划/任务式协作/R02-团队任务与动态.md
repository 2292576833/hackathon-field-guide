# R02 团队任务与动态

依据规划19与宪法v1.10.0。仅 `src/modules/team-collaboration/`、`src/components/team-task-board.tsx`、`src/components/team-task-board.module.css` 与 `docs/协作/交付/team-collaboration.md`。其他组件/M05服务/app/server/shared/根迁移主会话负责。

任务板效率优先，词条池+当前任务卡，显示负责人、依赖、待检查、检查通过、高亮与全队本阶段完成提示；点击才展开更多。不使用另一套任务表。词条池读取M05未生效草案任务，认领/退回调用根M05端口；草案归属变更仍需管理员校验确认，不能暗中改生效负责人。确认M05端口签名再组合；UI不猜造成功。

团队动态新增持久建议/决定卡：成员本人明确发布、编辑、撤回，管理员采纳，版本与作者/时间/来源回答ID记录；来源选择由服务器Port校验（本人导航/空间助手回答或本人选题报告），不信客户端自称AI。使用Port读取M05进度投影，与建议合并按时间排列，不直接写M05/M02表。未知/失效/撤回、归档/离队与重复请求不泄露旧内容。

导出公开类型、Postgres服务、SQL建议、动态UI组件和回答分享预览组件。API建议：GET/POST `/projects/:id/team-feed`，PATCH/withdraw/adopt卡片；GET `/projects/:id/task-pool`，POST草案claim/release由根。动态可见时轮询10秒，作者主动分享后才队内可见，微信仍承担自由聊天。

需要Port：当前项目访问/读只状态；M05进度与任务事实；本人回答来源校验。最终来源复核/项目权限必须同事务。用node:test验证CAS、权限、撤回不读取、只有经理采纳、并发/幂等；界面边距、主动作44px、无额外聊天群。交付停止后根统一组合。
