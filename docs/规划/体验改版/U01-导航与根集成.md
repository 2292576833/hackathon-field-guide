# U01 导航与根集成

日期：2026-10-09。负责人：主会话。依据：[总体改版规划](../13-体验优先与协作整合.md)。

## 目标与范围

让用户进入网站知道下一步，减少导航选择和重复返回。主导航使用“找比赛 / 我的参赛 / 工具与资料”；登录注册保留显眼入口，账号菜单收纳设置、固定队伍与有权限的后台。

主会话独占 SiteShell、CSS、首页、导航员、共享契约、实际迁移、server、app 路由、全站 E2E 与根配置。模块会话不安装依赖、重启服务或发布。

## 实施任务

1. 收敛主导航、显示当前位置、手机版易点按；账号菜单支持键盘关闭和失败提示。
2. 首页给“先找比赛 / 已有比赛开始准备”两种明确起点。
3. 资源页的二级分类统一；已有独立页面和查询参数继续可访问。
4. 初次导航仍能跳过、重放和详细阅读；简短起步说明与详细说明分层，保持 DSH 实际聊天及来源标签。
5. 审核 U02/U03 提出的共享接口和 SQL，复核权限及事务后组合。已应用迁移不可改写；本机当前最大迁移为 022，新增编号由主会话分配。
6. 更新旧页面断言，跑适合实际改动的检查。只读页面不能触发模型、邮件或外部写入。
7. 记录构建、浏览器与第三方验证的实际边界；保留数据库、发现账本及未知付费 hold。

## 验收

- 顶部只出现三个固定主要功能入口；手机无水平溢出，主操作至少 44px 高。
- 资源详情知道返回哪类；项目内知道当前阶段和下一步。
- 登录失效可回到当前页面，不能错误声称操作已完成。
- 未登录可看公开资料；项目与私人材料由后端复核。
- 官网赛事卡片仍显示实际保存分析，不恢复用户已要求移除的日期/报名过滤。
- 统一构建与只读浏览器检查通过后，主会话才决定替换运行版本。
