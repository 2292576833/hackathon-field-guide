# U04 资源中心与新手教程

日期：2026-10-09。独立会话实施。依据：[总体改版规划](../13-体验优先与协作整合.md)。

## 目标

让新人按“现在想做什么”找到工具、灵感、AI 技能或教程，不用猜多个资源库的区别。保留独立灵感/GitHub 页和经审核资源内容。

## 必须完成

1. /resources 是“工具与资料”入口，保留原工具筛选、收藏、分页、用途记录与主动分享到项目。
2. 根据任务给清楚说明：工具用于做事；灵感用于参考；AI 技能用于增强指定 AI 工具；新手教程用于理解操作。
3. 同一网站采用一致身份和链接，分别保留人工审核、DSH 官网分析和原创说明。不得把已审核外链状态直接升级为已完成 DSH 分析。
4. 处理重复的 GitHub 入门、组件/视觉网站和 PPT 工具说明，保留摘要与链接至主详情；跨页新共享接口需求先登记。
5. 技能筛选先问“你使用哪个 AI 工具、想完成什么”；许可、版本、兼容、安装清单按需展开，不能隐藏影响安装的关键条件。
6. “复制命令 / 写入文件 / 客户端加载 / 示例验证”继续独立显示。资源包分类清楚说明不代表比赛官方赛道。
7. 新手教程站内下一步链接正常显示；不接受协议相对地址、反斜杠、控制字符或未允许外部协议。
8. 详情页有返回所属目录入口，保留筛选参数；空结果给清除筛选或下一步，不只有“没有内容”。

## 文件授权

临时允许本会话修改：src/modules/resources/、src/modules/skills/；src/components/resource-hub.tsx、discovery-client.tsx、library-client.tsx、skills-client.tsx；交付文档 docs/协作/交付/ux-resource-center.md。

discovery-client.tsx 内同时包含赛事/规则组件，只允许资源页面与资源辅助入口相关改动，不能改赛事卡片、规则确认和项目草案逻辑。不得改 SiteShell、共享 CSS、github-guide.tsx（U03 持有）、src/server（包括 inspiration-catalog.ts 和 library.ts）、src/shared、src/app、实际迁移或根配置。

如要调整服务器原创文章或固定官网候选，写 NEEDS_INTERFACE 及准确修改建议；不得为了说明好看生成虚假 DSH 结果或重置发现/灵感预算。

## 验证与交付

验证资源发布/撤回、私人收藏、显式分享、技能许可与精确版本、链接安全和筛选保留。阅读页面不触发付费请求、安装或项目写入。

检查手机与桌面布局建议，实际浏览器统一由主会话执行。提供模块测试、组件、未接入需求和准确完成状态。没有新的版权推断或真实客户端验收时不能说技能已实测兼容。交付后停止编辑，不重启服务或发布。
