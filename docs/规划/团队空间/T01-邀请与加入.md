# T01 邀请与加入

依据宪法v1.7.0、规划16与空间规划14。实现常驻邀请弹窗、人数选择、生成后复制优先与本地QR；自定义/邮箱按需展开。既有token hash、72小时、1–50名额、明确接受与结果核对保留。

## 接入

导出 `SpaceInvitationTrigger({detail,onChanged}:{detail:ProjectDetail;onChanged:()=>Promise<void>})`，主会话在各空间页标题区渲染一次。管理员未归档按钮“邀请队友”；成员/归档显示权限说明。原生dialog支持Esc、关闭回焦点、手机滚动，关闭重开保留本次链接。初始 `#space-invitation` 可打开同一界面，ID唯一。

SpaceInvitation默认1人，按钮“生成邀请链接”；生成后“复制邀请链接”主要、“生成另一条邀请”次要。离页无法恢复需及时复制。创建记录真实invitation.id，以便只在对应撤销时清链接；先查真实回包不可捏造ID。高级及历史折叠，复制失败保留可选链接手动复制。

加入页按身份合并重复说明，保留限定邮箱/权限/只读预览/注册登录returnTo/明确接受。成功后可填写时间、选择职责、进入空间。
