# T02 任务与交接

依据宪法v1.7.0与规划16。精简任务卡，让成员知道现在能做、等待谁及如何提交成果。

修改 `src/components/team-task-board.tsx`；新增 `team-task-board.module.css`、`src/modules/planning/task-guidance.ts`、`task-guidance.test.ts`、`tests/e2e/team-space-tasks-v2.spec.ts`；交付 `docs/协作/交付/team-space-tasks-v2.md`。不改planning-client、task-board、共享导出/类型、API/数据库/旧测试；新helper直接显式.ts导入。

## 行为

本人可开始任务优先；保留全队筛选、10秒可见读取、权限丢失清除。无计划简短下一步，不显示空筛选。默认卡片名称/负责人/时间/状态/成果/主动作；工时、检查、历史按需展开。

等待项依据unmetDependencies显示真实前置名称、负责人和检查状态，链接同空间任务锚点；切换全队及状态让目标可见。可并行建议只用当前计划有效、已排时间、符合前置的ready任务；不得编造。负责人、协助和检查者分清。

“我已完成”改“提交成果，请队友检查”，继续review；检查通过保留证据、权限、自检说明。开始条件、纠错、误勾、并发输入恢复保留。TaskKind就地资源用途：开发调试测试→GitHub/资料；材料→PPT/路演/灵感；学习→资料/技能；提交→本空间delivery。不发模型、不读私人、不假报安装。
