## 实施

实现 `<JourneyTree guide={guide}/>`，guide 类型从 `model.ts` 引用，数据由 J01 提供。组件不请求 API、不保存打钩状态、不获取私人资料。

1. 树根“从找比赛到留下经验”，连接三阶段；阶段下显示行动，行动下引出工具/资料。使用 CSS 线、节点和缩进表达父子关系。不能以普通三列卡片替代树图。
2. 桌面三阶段分枝，手机沿左侧主干纵向展现，行动/资源继续缩进；内容可换行。树图不限于团队空间，必须能在公开新页独立使用。
3. 每阶段注意事项就近显示。操作链接文字清楚，辅助资源有使用时机与用途；可并行与可选说明不只依靠颜色。
4. 开头说明这是准备指南，主办方要求优先；具体依赖/真实进度在团队空间确认，报告完成需检查；私人材料不自动共享。不显示完成率或伪进度。
5. 阶段锚点便于跳转。语义使用 section/nav/ol/li，装饰线隐藏于辅助技术；不使用复杂 ARIA tree 或画布图替代可访问链接。
6. 暖白/炭黑/橙红延续本站；主要操作 44px、focus-visible、prefers-reduced-motion、375px 与 1280px 无横向溢出。不安装图形库或外部字体。
7. UI 公共入口 `ui.ts` 仅导出 JourneyTree，纯数据 `index.ts` 不属于本会话。

主会话负责 PageTitle/SiteShell、`/journey` 及全站入口，组件不要重复整页导航。J03 在新版 ready 后使用实际浏览器验收。可以先做源码类型检查，尚无模型文件时只报告依赖，不越界创建替代类型。
