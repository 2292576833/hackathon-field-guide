# J03 浏览器贯通验收

负责人：独立验收会话。依据：[参赛路线图总体规划](../15-参赛树状路线图.md)、宪法 v1.6.0。主服务当前正在运行，必须使用隔离内存 SQL 夹具。

## 文件授权

- `tests/e2e/journey.spec.ts`
- `docs/协作/交付/journey-acceptance.md`
- 本机截图/日志可写 `.runtime/previews/journey-*`、`.runtime/journey-*.log`，不提交敏感数据。

## 验收任务

1. 复用 `tests/e2e/ux-test.ts` 或 `isolated-workspace.ts`，用真实迁移和 HTTP handlers 的独立内存数据库。全部 API 拦截到夹具，阻断外网；不打开 `.runtime/postgres-data`，不发送真实验证码或调用付费 DSH/GitHub。
2. 游客直接读树根/三阶段/行动/资源分枝和注意事项，主导航仍为三项；不强制登录，不显示伪完成比例。
3. 验证首页、比赛、我的参赛、资源中心入口；路线图到 events/app/resources/inspiration/skills/github/roadshow/ppt/个人准备与复盘路径能继续；没有虚假 projectId。
4. 登录和注册保留 `/journey` 返回位置。已登录浏览指南也不能调用生成/写接口或查询其他团队项目；检查请求记录，不用静态假结果证明真实后端写入。
5. 375 与 1280px 实浏览器截图从 scrollY=0 拍摄；检查连接线层级、长中文、横向溢出、锚点和键盘焦点。
6. 先准备测试，等待主会话明确 ready 后再访问新路由；不在旧构建上把 404 误判为代码失败，不自行 build/重启主服务。
7. 发现源码缺陷在交付说明写清复现与位置，不越界修改组件/路由或共享夹具。主会话修复后只重跑相关失败场景。
8. 交付记录区分隔离浏览器、真实公网证书与实体手机。现有公网证书 UntrustedRoot 仍是已知限制，窄屏截图不能将它记作通过。

Constitution Check：VIII 验证真实可用路径并披露模拟边界；I/X 新人树图理解与手机操作；VI/VII 不泄露私人资料/令牌；IX 检查没有隐式收费或外部写入。纯 UI 检查不制造与实现重复的测试。
