# QQ 邮箱验证码配置

没有自有域名也可以使用 QQ 邮箱 SMTP。只需站长配置一个发件邮箱，用户可以填写自己使用的邮箱接收登录、注册验证码。

## 1. 取得发件邮箱授权码

登录 [QQ 邮箱](https://mail.qq.com)，在设置中查找账户或安全设置内的 SMTP 服务（新版界面可能归入客户端登录）。启用 SMTP，按页面要求完成身份验证，生成客户端授权码。需要填写的是这个授权码，不是 QQ 登录密码；不要把授权码发到聊天里。

腾讯官方说明：[Email 连接器中的 QQ 邮箱配置与授权码说明](https://cloud.tencent.com/document/product/1270/55456)。

## 2. 填入本机配置

在网站项目 `F:\黑客松情报局\.env.local` 中找到下面的配置。服务器、端口和加密方式已填好，发件邮箱暂用之前指定的管理员邮箱。若使用另一邮箱，改 `SMTP_USER` 并填写该邮箱生成的授权码。

```dotenv
AUTH_EMAIL_PROVIDER=smtp
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=2254391966@qq.com
SMTP_PASSWORD=在这里填该邮箱的授权码
```

保留其它网站配置。`AUTH_EMAIL_FROM` 可以不填；默认显示“黑客松情报局”，地址使用 `SMTP_USER`。若已有 `AUTH_EMAIL_FROM`，地址必须与 `SMTP_USER` 一致。

填好后重启网站服务，再在网站的注册或登录页请求一次验证码，检查收件箱和垃圾邮件箱。SMTP 服务器接受邮件后才会显示发送成功；最终是否到达收件箱仍需实际核实。

## 3. 常见问题

| 现象 | 处理 |
| --- | --- |
| 网站提示暂时无法发送 | 授权码尚未填好或服务尚未重启 |
| 配置后仍发送失败 | 确认 SMTP 服务开启、授权码属于该发件邮箱、账号未被邮箱服务限制 |
| 提示冷却时间 | 等待页面显示的时间，不连续请求 |
| 显示发送成功但未收到 | 检查输入邮箱拼写与垃圾箱；稍等后再检查，不保证所有邮箱立即投递 |

QQ 邮箱适合当前少量队伍试用，后续用户增长时再根据发信限制和到达率考虑专业邮件服务。
