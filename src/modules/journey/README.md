# 公开参赛路线图

J01 提供 `/journey` 使用的本站原创通用准备指南。内容从找比赛开始，串联赛前、赛中、赛后，以及对应的团队空间、个人准备、工具、灵感、技能、GitHub、路演/PPT 和复盘入口。

## 公共接口

```ts
import { getJourneyGuide, validateJourneyGuide, isJourneyHref } from "./index.ts";
import type { JourneyGuide } from "./index.ts";

const guide: JourneyGuide = getJourneyGuide();
const errors = validateJourneyGuide(guide); // 正常内容返回 []
```

- `model.ts` 是 `JourneyGuide`、`JourneyRoot`、`JourneyAction`、`JourneyPhase`、`JourneyNode`、`JourneyResource` 和站内链接类型的唯一来源。
- `getJourneyGuide(): JourneyGuide` 返回独立的公开内容快照。字段为只读类型；即使运行时消费方改动快照，也不会污染后续读取。
- `validateJourneyGuide(guide)` 是针对已编写指南的纯校验函数，返回错误列表。它检查三阶段及顺序、全树 ID 唯一、必需文字、注意事项、资源用途、真实入口白名单和额外字段。它不作为任意用户 JSON 的解析器。
- `isJourneyHref(href)` 只接受确认的完整路径；不接受外站、API、管理员入口、项目占位 ID、查询参数或路径变体。
- `index.ts` 只导出纯内容、纯函数和类型，不导入 TSX、服务器应用、账号、数据库或外部服务。J02 的界面由独立 `ui.ts` 导出。

树根提供“先找比赛”和“打开我的团队空间”。三阶段包含 15 个行动节点，每个节点有具体操作说明、操作入口和资源子枝。`parallel` 为可见并行说明或 `null`，不代表任务依赖已经满足。

## 内容依据与边界

依据为宪法 v1.6.0、`docs/规划/15-参赛树状路线图.md`、J01 规划和本轮分工登记。本站栏目、六篇教程和功能边界通过现有源码核对；未新增外站推荐或外部许可结论。

- 主办方最新要求优先。赛事 DSH 分析是未核验线索，资格、报名、官方赛道、AI 使用规则和各项截止分别核对。
- `/library` 是本站原创说明；`/resources` 是经运营审核的工具与资料；`/inspiration` 区分已完成但未经人工核验的 DSH 说明与等待分析的官网条目。
- 单人也可创建团队空间；邀请、职责、计划、任务、运行检查、正式提交、复盘与归档入口全部先到 `/app`，由用户选择真实空间。没有生成项目深链或虚假 ID。
- `/participation` 提醒先从比赛卡片选赛事；本人画像、出行、准备、讲稿、PPT 和收藏不会通过指南自动共享。生成和保存需登录及明确动作。
- 成员可自选多项职责，也可使用 AI 帮助，正式分工由管理员确认。工具与技能是按需辅助，不作为强制前置；复制、安装、加载与示例验证分别说明。
- 准备顺序不复制任务依赖。UI 草图、素材、测试样例和讲稿/PPT 大纲可以提前并行；实际运行检查需要可运行版本，视频成片需要可演示成果。
- 代码保存、实际运行检查和主办方正式提交分别记录。复盘引用既有交付事实，不另建成功状态。

首版没有账号或 `projectId` 数据、打钩、完成率、私人进度、数据库迁移、后台任务、新依赖或付费调用。浏览指南不会创建空间、报名、安装技能或修改仓库。
